# Spotify Web Player Clone 🎵

A Spotify-inspired music streaming web player UI built using HTML and CSS. This project recreates the look and feel of Spotify's web player with a sidebar, music cards, navigation bar, and music player controls.

## 🔴 Live Demo

👉 [View Live Demo](https://spotify-clone-eosin-xi-92.vercel.app/)


## Features

- Spotify-inspired dark UI
- Home and Search navigation
- Your Library section
- Recently Played section
- Trending music section
- Featured Charts
- Music player controls
- Play/Pause interface
- Music progress bar
- Responsive layout
- Font Awesome icons
- Custom project assets

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts (Montserrat)

## How to Run

1. Download or clone this repository.

2. Open the project folder in VS Code.

3. Make sure `index.html`, `style.css`, and the `assets` folder are in the correct locations.

4. Open `index.html` in your browser.

### Using Live Server

If you are using VS Code:

1. Install the **Live Server** extension.
2. Right-click on `index.html`.
3. Select **Open with Live Server**.
4. The Spotify Clone will open in your browser.
